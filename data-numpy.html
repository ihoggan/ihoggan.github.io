NumPy with penguins

Between 2007 and 2009, scientists in Antarctica measured 344 penguins: their bills, their flippers, their weight. Over five steps, you'll use the same four tools data scientists use every day to explore those measurements, find the patterns, and finally teach a computer to tell the species apart. This first step is NumPy, the part everything else is built on. The Python runs live in your browser. Nothing to install, and nothing you type leaves your machine.

Part 2

Why not just a Python list?

Python has its own way to hold a row of things: a list, in square brackets. It looks almost the same. It isn't.

Predict first

Both lines below "multiply by 2". Write down what you think each one gives.

What happened

The list was repeated: [181, 186, 181, 186]. The array was doubled: [362 372]. A list is a row of things; Python doesn't assume they're numbers. An array is a row of numbers, so maths means maths. When you're working with data, that's almost always what you want.

All 344 penguins

The full study is in a file called penguins.csv: one line per penguin, values separated by commas. Column 4 (counting from 0) is flipper length. Load the whole column:

Look closely at the first ten. One of them isn't a number. Now for the most important lesson in this whole path.

Predict first

What will the average flipper length of all 344 penguins be?

Why it said nan

nan means "not a number". Two penguins have no flipper measurement: maybe the bird wouldn't keep still. In the file they're written NA, and NumPy loads them as nan. Any sum that includes "unknown" is unknown, so the average is unknown too. Real data almost always has gaps, and the first job is always to find them.

np.isnan gives a True or False for every penguin. .sum() counts the Trues, because True counts as 1. np.nanmean is the average, skipping the gaps: about 201 mm.

Lesson

Always ask "is anything missing?" before you trust an average. A nan that shouts is a gift. The dangerous gaps are the quiet ones.

Part 4

Asking questions with masks

A comparison works on the whole array too, and gives one True or False per penguin. That row of answers is called a mask, and you can use it to pick penguins out.

Experiment

Change 210 to 225 and run it again. How many penguins have flippers longer than 225 mm? What's the longest? Try np.nanmax(flippers) in a box of its own.

Masks can be combined: & means "and", | means "or", and each comparison goes in brackets.

Part 5

Your turn: the heavyweights

Column 5 is body mass, in grams. Load it, and turn it into kilograms:

Challenge

What fraction of the weighed penguins are over 4.5 kg? You need two counts: how many are over 4.5, and how many were weighed at all. Everything you need is on this page. Write it in the empty box.

One way to do it 
heavy = (mass_kg > 4.5).sum()
weighed = (~np.isnan(mass_kg)).sum()   # ~ means "not"
heavy / weighed

115 of 342, about 0.34: roughly a third. Did you remember that two penguins weren't weighed? Dividing by 344 instead gives a slightly wrong answer, and no error to warn you. That's one of the quiet gaps.

Part 6

A hint of what's coming

Do penguins with longer flippers tend to be heavier? NumPy can put a number on "tend to". It's called correlation: 1 means "always rise together", 0 means "no connection", and −1 means "one rises as the other falls".

Predict first

Somewhere between 0 and 1. Closer to which?

About 0.87: a strong connection. But a single number hides a lot. Are all three species the same? Is it a straight line, or a curve? In step 3 you'll draw it and see for yourself. First, the numbers need a better home than loose rows. Step 2 gives them a proper table.

Check

You can make an array, do maths on all of it at once, find the missing values, and pick out rows with a mask.

On your own machine

Run it without the browser

Everything above works in ordinary Python on Ubuntu too, and then it works offline. Set up one folder for the whole path, with its own virtual environment (a private box of Python libraries, so nothing touches the system's Python):

sudo apt install python3-venv          # once, if you don't have it
mkdir -p ~/code/data-path && cd ~/code/data-path
python3 -m venv venv
source venv/bin/activate               # your prompt now starts with (venv)
pip install numpy pandas matplotlib scikit-learn
curl -fsSLO https://ihoggan.github.io/data/penguins.csv

That installs all four libraries for the whole path, from the official Python package index, into that folder only. Then type python3 and paste the boxes in, in order, or save them to a file and run python3 step1.py. Next time, just cd ~/code/data-path && source venv/bin/activate.

That's step 1

What I'd want you to take away

Write it once

An array does the same maths to every number in the row. No loops.

Find the gaps first

nan spreads through every sum it touches. Count the missing values before you trust an answer.

Masks ask questions

A comparison gives True or False per row. Count them, or use them to pick rows out.
