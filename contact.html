GitHub is the best place to reach me. Found a mistake in one of these projects? Open an issue — corrections are genuinely welcome, and several of these pages are better because someone told me I was wrong.

What to send where

Issues

Something's broken

A page that won't load, a command that doesn't work, a number that looks wrong. Open an issue on the relevant repository with what you did and what happened.

Pull requests

You've fixed it

Even better. Fork it, fix it, send it over. Small corrections are as welcome as large ones — a typo fix is a real contribution.

Discussions

A question

Stuck partway through one of the guides, or want to know why something was built a particular way? Ask — if the answer isn't obvious, the page needs improving.

Teaching use

Using these with a class

All of it is MIT licensed and free to use in teaching. I'd like to hear about it if you do, and I'll happily adjust something to make it fit a lesson.
