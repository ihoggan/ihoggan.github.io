# ihoggan.github.io

The source of my site: **https://ihoggan.github.io/**

I'm Iain Hoggan, a network technician on the Wirral. I build things on hardware other people throw away, and I measure them honestly, including when the measurement says I'm wrong.

## What's on it

**Case studies**
- [Saved from the scrap pile](https://ihoggan.github.io/reclaim.html): a 2015 office PC headed for scrap, now running Ubuntu, a local AI model and characters that remember me. Includes the measurement that showed the characters' memories were almost entirely invented, and the fix. Code: [localcast](https://github.com/IHoggan/localcast), [nix6-tools](https://github.com/IHoggan/nix6-tools).
- [HUSTLER](https://ihoggan.github.io/Hustler.html): a UK blackball pool physics sandbox built over seventy revisions, and what the bugs taught me about testing.

**Things you can run in your browser**
- [S.M.A.R.T.](https://ihoggan.github.io/neural_playground.html): watch a single neuron learn, then push the learning rate until it breaks.
- [TradeWar](https://ihoggan.github.io/TradeWar.html): trade against a rule-following bot and see how long your discipline lasts.

**Archive (2025):** beginner guides to Linux, Python and the Raspberry Pi, and a rocks and minerals reference.

## How it's built

Plain HTML and CSS, one shared stylesheet (`site.css`), no build step, hosted on GitHub Pages. Every page works on a phone.
